## Deferred design boundary

本 skeleton future ownership 为 Node health、固定 `GET /healthz` connection test、immediate Monitoring Enable/Disable、admin API/UI、CSRF/audit 和 shared receipt reuse。不得增加 scheduled monitoring product API、credential/account mutation 或 arbitrary HTTP client。

Operations MUST reuse the approved shared command receipt/advisory lock/intent/revision/compatibility foundation through the Node lifecycle change dependency。详细 transaction、OpenAPI、UI、tests 和 tasks planning deferred until that dependency is approved。
